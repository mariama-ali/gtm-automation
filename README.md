<h2 id="overview">Overview</h2>

<p>
  GTM Automation Platform is a full-stack portfolio project
  designed to automate sales workflows, organize lead data,
  and integrate AI-powered research and enrichment.
</p>

<h2 id="key-features">Key Features</h2>

<ul>
  <li><strong>Dashboard:</strong> KPI cards and activity overview</li>
  <li><strong>Lead Management:</strong> Import, filter, and qualify leads</li>
  <li><strong>CRM:</strong> Track companies, contacts, and pipeline stages</li>
  <li><strong>AI Agents:</strong> Planned account research and lead qualification</li>
  <li><strong>Automation:</strong> Planned API integrations and workflow execution</li>
  <li><strong>Analytics:</strong> Planned performance reporting</li>
</ul>

<h2 id="tech-stack">Tech Stack</h2>

<p>
  <strong>Frontend:</strong> Next.js, React, TypeScript, Tailwind CSS<br>
  <strong>Backend:</strong> Next.js, Supabase<br>
  <strong>Database:</strong> PostgreSQL<br>
  <strong>Authentication:</strong> Supabase Auth<br>
  <strong>Development:</strong> Git, GitHub, OpenAI Codex
</p>
